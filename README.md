# Resume Studio

A native Java and Android resume builder for Pynexia Android Development, Week 4. Complete a three-step resume form, preview it, and save a PDF with the Android document picker.

## Build

Open this folder in Android Studio with JDK 17 or 21 and Android SDK 35. The included debug APK is available in the [latest release](https://github.com/ENGEyad/pynexia-week4-resume/releases/latest).

```powershell
.\gradlew.bat :resume:assembleDebug :resume:lintDebug
```
