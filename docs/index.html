A resume that moves with you.

Resume Studio is a focused Android app for building a polished CV on your phone. Enter your details, preview the result, then save a PDF wherever you need it.

View source on GitHubGet the Android APK & report

Designed around a simple flow

01 · Profile
Contact details and a concise introduction.
02 · Background
Education and work experience in clear sections.
03 · Review
Add skills, preview the CV and export a PDF.

What’s included

  • Field checks for the name and email.
  • Private local draft saving, including after restarting the app.
  • Live preview built from the entered details.
  • Paginated PDF output through Android’s file picker.
  • No account, network connection or broad file permissions required.

Try it

  1. Install the APK on an Android device or emulator.
  2. Complete the three form steps and open the preview.
  3. Select Download PDF and choose a destination.
  4. Reopen the app to see the saved draft.
